# Орбита — личный ИИ-ассистент для рабочего стола

Ассистент живёт в строке меню (или в трее) и появляется поверх любого окна по горячей клавише.
Он видит, с чем вы работаете — активное окно, скопированный или выделенный текст, — и сразу
предлагает подходящие действия. Ответы даёт Claude через Anthropic API.

Electron + чистые HTML/CSS/JS, без сборщиков. Дизайн — в духе macOS, светлая и тёмная темы
переключаются вслед за системой.

## Запуск

```bash
cd orbita
npm install
npm start
```

При первом запуске откроются настройки — вставьте API-ключ Anthropic
(его можно получить на platform.claude.com). Вместо этого можно задать переменную окружения
`ANTHROPIC_API_KEY`.

## Что умеет

| Где | Что |
|---|---|
| **Быстрый вызов** `⌥ Space` | Панель как у Spotlight. Показывает активное окно и текст из буфера обмена и предлагает действия: пересказать, перевести, исправить, набросать ответ, найти в файлах. Ответ приходит потоком прямо в панели. Его можно вставить в окно, из которого вы пришли (`⌘↩`), скопировать, уточнить или открыть в чате. |
| **Спросить о выделенном** `⌥ A` | Копирует выделенный текст в любом приложении и открывает с ним панель. |
| **Основное окно** `⌥ ⇧ Space` | Чат с историей и поиском по разговорам. Можно прикреплять PDF, текстовые файлы и изображения. Справа — панель «Сведения»: файлы разговора и то, что Орбита о вас помнит. |
| **Меню в трее** | Плитки в стиле Пункта управления. Через них можно: <br>• спросить Орбиту; <br>• включить или выключить чтение активного окна и буфера обмена; <br>• включить «Не беспокоить» (горячие клавиши встают на паузу); <br>• настроить автозапуск. <br>Там же — недавние разговоры. |
| **Настройки** | Сочетания клавиш (меняются нажатием), что видит Орбита, папки для поиска файлов, модель (Opus 5.5 / Sonnet 5.5), API-ключ, память, цвет акцента. |

У Claude есть три локальных инструмента:

- `search_files` ищет по именам файлов в разрешённых папках (по умолчанию «Документы», «Загрузки», «Рабочий стол»). На macOS он ищет ещё и по содержимому через Spotlight.
- `read_file` читает текстовые файлы, PDF и изображения, но только из разрешённых папок или из вложений.
- `remember` сохраняет факт о вас в долговременную память. Она подмешивается в каждый разговор.

## Права доступа

- **macOS.** Чтобы знать активное окно, вставлять ответ и копировать выделенное, Орбите нужен доступ в
  «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ». Без него всё
  остальное работает, а ответ просто копируется в буфер обмена.
- **Windows** — дополнительных разрешений не нужно (используется PowerShell).
- **Linux** — для активного окна и вставки нужен `xdotool` (`sudo apt install xdotool`).

## Приватность

- Настройки, память и история хранятся в одном файле `orbita.json` в папке данных приложения.
- API-ключ шифруется средствами ОС (Keychain, DPAPI, libsecret), если они доступны.
- Буфер обмена читается только в момент вызова панели.
- Запросы уходят напрямую в Anthropic API.

## Устройство

```
main.js            окна, трей, горячие клавиши, IPC
preload.js         безопасный мост window.orbita (contextIsolation + sandbox)
src/assistant.js   разговоры, стриминг Claude, цикл инструментов
src/store.js       настройки, память, история (JSON в userData)
src/context.js     активное окно, копирование выделенного, вставка — для каждой ОС
src/icon.js        иконка трея, рисуется в PNG на лету
renderer/          панель, основное окно и меню трея (HTML/CSS/ES-модули)
scripts/           проверки и смоук-тест
```

Запросы идут через `client.beta.messages.stream` с моделью `claude-opus-5-5` (или `claude-sonnet-5-5`).

- Глубина рассуждений (`effort`): `low` для панели, чтобы ответ приходил быстро, `medium` для чата.
- Включён серверный фолбэк: если модель отказывается отвечать, запрос автоматически повторяется на подходящей модели.
- Включено кэширование промпта.
- Ответы модели дописываются в историю целиком и без изменений.

## Проверки

```bash
npm run check   # синтаксис всех файлов + тесты Markdown-рендера
npm run smoke   # сквозной тест (на Linux без экрана: xvfb-run -a npm run smoke)
```

Смоук-тест запускает настоящее приложение против локального мока Messages API. Он проходит по
шагам:

1. Открывает чат с вызовом инструмента.
2. Показывает настройки.
3. Вызывает панель и получает быстрый ответ.
4. Открывает меню в трее.
5. Включает тёмную тему.

На каждом шаге сохраняются скриншоты в `screenshots/`. В конце тест проверяет, что именно ушло в API.
